# ストア立ち上げ手順（チェックリスト）

上から順に進めると、テーマが想定どおりに表示される状態になります。所要時間の目安は 2〜3 時間です（写真の撮影・差し替えを除く）。

## 1. 基本設定
- [ ] ［設定］→［ストアの詳細］：ストア名「ROtailor」、連絡先メール、住所
- [ ] ［設定］→［通知］：お問い合わせ・来店予約フォームが届くメールアドレス
- [ ] ［設定］→［配送と配達］：全国一律送料と、送料無料の条件（例：税込 11,000円以上）
- [ ] ［設定］→［税］：税込価格で表示
- [ ] ［設定］→［ポリシー］：返品・プライバシー・利用規約・特定商取引法に基づく表記（フッターに自動で表示されます）
- [ ] ［設定］→［お客様アカウント］：会員機能を使うかどうか

## 2. カスタムデータ（メタフィールド）を作る
［設定］→［カスタムデータ］で次を作成します。**商品 CSV を取り込む前に作ってください**（先に作っておくと CSV の値が取り込まれます）。

| 対象 | 名前 | ネームスペースとキー | タイプ |
| --- | --- | --- | --- |
| 商品 | テイラーのひとこと | `custom.tailor_comment` | 複数行テキスト |
| 商品 | 合わせたい小物 | `custom.pairing_products` | 商品（リスト） |
| 商品 | 合うスーツのヒント | `custom.suit_pairing_hint` | 1行テキスト |
| 商品 | 素材 | `custom.material` | 1行テキスト |
| 商品 | 生産国 | `custom.origin` | 1行テキスト |
| 商品 | お手入れ | `custom.care` | 複数行テキスト |
| ブログ記事 | 紹介アイテム | `custom.related_products` | 商品（リスト） |

生地をたくさん登録する場合は、メタオブジェクト `suit_fabric` も作ります（README の「生地が多い場合」を参照）。

## 3. 商品を取り込む
- [ ] ［商品］→［インポート］で `products-rotailor.csv` を選ぶ（STORES の商品をもとにした実データ）
  - 18 商品（ネクタイ 12／シューズ 4／バッグ 2）が、価格・説明・写真付きで**下書き状態**で入ります
  - 在庫は各 1 点。内容を確認して「アクティブ」にすると公開されます
  - ブランド名（ベンダー）はすべて「ROtailor」にしてあります
- [ ] 各商品の「合わせたい小物」で、一緒に提案したい商品を選ぶ（例：ストレートチップ → シューツリー、レザーベルト）

## 4. コレクション（カテゴリ）を作る
［商品］→［コレクション］→［コレクションを作成］で「自動」を選び、条件を設定します。

| コレクション名 | 条件 |
| --- | --- |
| シューズ | 商品タイプ が「シューズ」と等しい |
| バッグ | 商品タイプ が「バッグ」と等しい |
| ネクタイ | 商品タイプ が「ネクタイ」と等しい |
| ベルト・小物 | 商品タイプ が「ベルト・小物」と等しい |
| 新着 | 価格が 0 より大きい（並び順：新しい順） |
| ネイビーのスーツに | 商品タグ が「ネイビー」または「ブラウン」と等しい など自由に |
| 結婚式・式典に | 商品タグ が「結婚式」と等しい |

### 絞り込み（色・価格など）
- [ ] アプリ「Search & Discovery」（Shopify 公式・無料）を追加し、［フィルター］で「在庫状況」「価格」「商品タイプ」「タグ」などを設定すると、コレクションページに絞り込みが表示されます。

## 5. ページを作る
［オンラインストア］→［ページ］で作成します。本文は `content/` フォルダの HTML を、エディタの「HTML を表示」に貼り付けてください。

| ページ | テンプレート | 本文 |
| --- | --- | --- |
| ROtailorについて | `page.about` | `content/page-about.html` |
| オーダースーツを仕立てる | `page.simulator` | 不要（シミュレーターが表示されます） |
| お問い合わせ | `page.contact` | 任意 |
| サイズガイド | `page`（標準） | `content/page-size-guide.html` |
| 配送・返品について | `page`（標準） | `content/page-shipping.html` |

## 6. ブログ
- [ ] ［オンラインストア］→［ブログ記事］→［ブログを管理］で「テイラーの手帖」を作成
- [ ] 最初の記事として `content/blog-01〜03` を貼り付け、タグ（着こなし／お手入れ など）を付けて公開

## 7. メニュー
［オンラインストア］→［メニュー］

**メインメニュー（main-menu）**
- アイテム（/collections/all）
  - シューズ／バッグ／ネクタイ／ベルト・小物
- スーツの色から選ぶ（/#pairing などトップへ。またはコレクション「ネイビーのスーツに」）
- オーダースーツ（ページ「オーダースーツを仕立てる」）
- テイラーの手帖（ブログ）
- ROtailorについて

**フッターメニュー（footer）**
- サイズガイド／配送・返品について／お問い合わせ／ROtailorについて

## 8. テーマエディタで仕上げ
［オンラインストア］→［テーマ］→［カスタマイズ］
- [ ] テーマ設定：ロゴ、配色、店舗情報、予約ページの URL、SNS、送料無料の金額
- [ ] ヘッダー：「シミュレーションのページ」を選択
- [ ] トップページ：メイン画像、カテゴリ画像とコレクション、「スーツの色から選ぶ小物」のおすすめ商品、ブログ
- [ ] 商品ページ：「サイズガイド」ブロックにサイズガイドのページを選択
- [ ] シミュレーション：生地・選択肢の差し替え、AI テイラーの API URL（使う場合）

## 9. 公開前の確認
- [ ] スマートフォンで全ページを確認
- [ ] テスト注文（［設定］→［決済］のテストモード）でカート〜購入完了まで確認
- [ ] お問い合わせフォームと来店予約フォームが届くか確認
- [ ] パスワード保護を外して公開
