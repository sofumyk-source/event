# ROテイラー オンラインストア（Shopify テーマ）

ROテイラーが扱うシューズ・バッグ・ネクタイなどの**小物を中心にした EC サイト**向けの Shopify テーマです（Online Store 2.0 対応）。

- **ブランドの発信**：トップページのブランドストーリー、店舗案内、来店予約への導線
- **テイラーならではの小物提案**：「スーツの色から選ぶ小物」、商品ごとの「テイラーのひとこと」、合わせ小物の表示
- **ブログ**：Shopify 標準のブログ機能を使用し、カテゴリ（タグ）絞り込みと記事内の紹介商品に対応
- **オーダースーツ・シミュレーション**：生地・ディテールを選ぶとイラストの一着がその場で変わる、着せ替え感覚で楽しめる自社仕様のシミュレーター。価格は表示せず、お見積もりはサロンでご案内する導線

```
rotailor-shopify/
├── theme/                 … Shopify にアップロードするテーマ本体
│   ├── layout/            … 全ページ共通の枠（theme.liquid / password.liquid）
│   ├── sections/          … テーマエディタで並べ替えできるパーツ
│   ├── snippets/          … 商品カードなどの部品
│   ├── templates/         … ページごとの構成（JSON）
│   ├── assets/            … CSS / JavaScript（suit-simulator.js がシミュレーター本体）
│   ├── config/            … テーマ設定（色・店舗情報・SNS など）
│   └── locales/           … 日本語の文言
├── stylist-api/             … AI テイラーの API（Cloudflare Workers）
├── demo/simulator-demo.html … Shopify なしで動くシミュレーターのデモ（ブラウザで開くだけ）
└── tools/build-demo.py      … デモの再生成スクリプト
```

## 1. 導入手順

### テーマのアップロード

**A. Shopify CLI を使う場合（推奨）**

```bash
cd rotailor-shopify/theme
shopify theme dev --store <ストア名>.myshopify.com   # ローカルでプレビュー
shopify theme push --unpublished                     # 非公開テーマとしてアップロード
shopify theme check                                  # 構文チェック
```

**B. 管理画面からアップロードする場合**

`theme` フォルダの**中身**を zip にまとめ（`layout/` などが zip の直下に来るように）、
管理画面［オンラインストア］→［テーマ］→［テーマを追加］→［zip ファイルをアップロード］。

### ストア側で用意するもの

| 項目 | 設定場所 | 内容 |
| --- | --- | --- |
| メニュー | コンテンツ → メニュー | `main-menu`（ヘッダー）、`footer`（フッター）。例：シューズ／バッグ／ネクタイ／小物／ジャーナル／ROテイラーについて |
| コレクション | 商品 → コレクション | シューズ、バッグ、ネクタイ、ベルト・小物、新着 など |
| ページ「ROテイラーについて」 | オンラインストア → ページ | テンプレート **page.about** を選択 |
| ページ「オーダースーツを仕立てる」 | 同上 | テンプレート **page.simulator** を選択（ハンドルは `suit-simulator` 推奨） |
| ページ「お問い合わせ」 | 同上 | テンプレート **page.contact** を選択 |
| ブログ「テイラーの手帖」 | オンラインストア → ブログ記事 → ブログを管理 | トップページの［ブログ記事］セクションで選択 |

そのあとテーマエディタで次を設定します。

1. **テーマ設定 → ブランド**：ロゴ、ファビコン、SNS 用画像
2. **テーマ設定 → ご来店・ご予約**：予約ページの URL（STORES 予約・RESERVA などの外部予約システムや、お問い合わせページ）、住所、営業時間、電話番号
3. **ヘッダー**：「シミュレーションのページ」に上で作ったページを指定
4. **トップページ**：各セクションの画像・コレクション・ブログを選択

## 2. テイラーならではの小物提案

### トップページ「スーツの色から選ぶ小物」
スーツの色（ネイビー／チャコール／ブラウンなど）ごとに、テイラーの解説、ネクタイ・靴・バッグの合わせ方、おすすめ商品を表示します。色はブロックとして追加・削除でき、最大 6 色です。

### 商品ページのメタフィールド
管理画面［設定］→［カスタムデータ］→［商品］で、次の定義を作成してください。

| 名前 | ネームスペースとキー | タイプ | 表示される場所 |
| --- | --- | --- | --- |
| テイラーのひとこと | `custom.tailor_comment` | 複数行テキスト | 商品ページ（真鍮色の線付きのコメント枠） |
| 合わせたい小物 | `custom.pairing_products` | 商品（リスト） | 商品ページ下部「テイラーが選ぶ、合わせたい小物」 |
| 合うスーツのヒント | `custom.suit_pairing_hint` | 1行テキスト | 価格の下（例：ネイビー・グレーのスーツに） |
| 素材 | `custom.material` | 1行テキスト | 仕様・素材 |
| 生産国 | `custom.origin` | 1行テキスト | 仕様・素材 |
| お手入れ | `custom.care` | 複数行テキスト | お手入れ |

`pairing_products` が空の商品では、Shopify の自動レコメンド（関連商品）が代わりに表示されます。

## 3. ブログ

Shopify 標準のブログ機能を使うため、**記事の追加・編集は管理画面［コンテンツ］→［ブログ記事］から行えます**（スマートフォンの Shopify アプリからも更新可能）。

- **カテゴリ**：記事の「タグ」がカテゴリとしてブログ一覧に表示されます（例：着こなし／新入荷／お手入れ／サロンだより）
- **紹介商品**：［設定］→［カスタムデータ］→［ブログ記事］に `custom.related_products`（商品・リスト）を作ると、記事の下に紹介商品が並びます
- **執筆者の紹介文**：テーマエディタのブログ記事テンプレートで編集できます
- 記事ページの下にはシミュレーションへの案内を表示しています（テーマエディタで外せます）

## 4. オーダースーツ・シミュレーション

`page.simulator` テンプレートのページに表示されます。デモは `demo/simulator-demo.html` をブラウザで開くと確認できます。

### お客様の操作の流れ
0. **イメージから仕立てる**（任意）：やりたいことを言葉で入力すると、テイラーが一着を仕立てる（下記）
1. **生地**：シーズンで絞り込み、生地を選ぶ
2. **型**：シングル 1B／2B／3B 段返り／ダブル 6B／4B、ラペル（ノッチ／ピーク／ショール・幅）
3. **ディテール**：腰ポケット、ベント、ボタン、裏地
4. **パンツ・ベスト**：タック、裾、スリーピース
5. **オプション**：本切羽、ネーム刺繍（文字入力）、台場仕立て、スペアパンツ など
6. **Vゾーン**：ネクタイとシャツの色を合わせる
7. **仕上がり**：完成イラストと仕様一覧 →「お見積もりは、サロンで。」の案内と来店予約フォーム

**価格は一切表示しません。** 生地・仕立て方・サイズで価格が変わるため、仕上がり画面で「お見積もりはサロンで」と案内し、来店予約につなげます。
「おまかせ」ボタンでランダムな組み合わせも楽しめます。イラストは前・後ろを切り替えられ、ベントは後ろ姿で確認できます。選んだ内容はブラウザに保存されるほか、「この内容のリンクをコピー」で URL として共有できます（URL を開くと同じ内容が再現されます）。

### イメージから仕立てる（AI テイラー）
シミュレーターの一番上に「どんな一着にしたいですか？」という入力欄があります。お客様が「秋の夕暮れ、港町のレストランで大切な人と食事をする日に」のように自由に書くと、テイラーがその言葉から生地・型・ラペル・ボタン・裏地・ネクタイまでを選んで一着を仕立て、一着の名前とテイラーのひとことを添えて返します。仕上がったあとも、お客様は手動で細部を着せ替えられます。

- **AI 版**（`stylist-api/`）：Claude（Anthropic の AI）が自由な文章を読み取ります。選べる値はテーマエディタに登録した選択肢に限定しているため、存在しない生地を返すことはありません。キャラクター名やブランド名が入力されても、返答では固有名を使わず、色と雰囲気だけで表現するよう指示しています。価格には触れません。
- **内蔵版**（`theme/assets/suit-stylist.js`）：API が未設定・通信できないときに自動で使われます。季節・場面・気分・色・景色など約 35 種類の言葉の辞書から好みを推定して仕立てます。同じ言葉なら毎回同じ一着になります。お店側での用語の準備は不要です。

#### AI 版の公開手順（Cloudflare Workers・無料枠で運用可能）
1. [Anthropic Console](https://console.anthropic.com/) で API キーを発行し、利用上限（月額の上限金額）を設定する
2. Cloudflare のアカウントを作成し、次を実行する
   ```bash
   cd rotailor-shopify/stylist-api
   npm install
   npx wrangler login
   npx wrangler secret put ANTHROPIC_API_KEY   # 発行したキーを貼り付け
   npx wrangler deploy
   ```
3. `wrangler.toml` の `ALLOWED_ORIGINS` にストアの URL（独自ドメインと `xxx.myshopify.com` の両方）を書いて、もう一度 `npx wrangler deploy`
4. 表示された URL の末尾に `/style` を付けて、テーマエディタ →シミュレーションのセクション →「AI テイラーの API URL」に貼り付ける

悪用対策として、許可したストアのドメインからしか呼べないようにしています。あわせて、1 つの IP アドレスから 1 分に 10 回までに制限し、入力は 200 文字までにしています。

#### 費用の目安（1 ドル＝150 円で計算）
| 使うモデル（`wrangler.toml` の `STYLIST_MODEL`） | 1 回あたり | 月 1,000 回 |
| --- | --- | --- |
| `claude-opus-5-5`（初期設定・最も表現力が高い） | 約 3〜4 円 | 約 3,500 円 |
| `claude-haiku-5-5`（軽量・高速） | 約 0.1 円 | 約 100 円 |

1 回の入力（選択肢一覧 約 3,000 トークン）と出力（約 600 トークン）から見積もった概算です。選択肢を増やすと少し上がります。

### こだわりの反映方法（コード編集は不要）
テーマエディタでシミュレーションのページを開くと、すべての選択肢が**ブロック**として並んでいます。

| ブロック | 設定できること |
| --- | --- |
| 生地 | 生地名、ミル、産地、組成・目付、シーズン、色、柄（無地／ピンストライプ／チョーク／ウィンドウペン／グレンチェック／ヘリンボーン／バーズアイ）、**生地の写真**、テイラーのコメント、**この生地に合わせたい小物** |
| ジャケットの型・ラペル・腰ポケット・ベント・パンツのタック・裾 | 名称、イラストの形、説明 |
| ボタン・裏地 | 名称、色（裏地は柄・写真も可）、説明 |
| オプション | 名称、説明、文字入力欄の有無 |
| Vゾーン（ネクタイ） | 色・柄、シャツの色、**対応する商品**（確認画面で小物として提案されます） |

セクション設定では、スリーピースを選べるかどうか、仕上がり画面の見出しと「お見積もりはサロンで」の案内文、来店予約フォームの文言、生地ごとの提案がない場合に表示する商品を設定できます。

> **初期データについて**：生地のミル名・選択肢は**仮のサンプル**です。実際の取り扱い生地とディテールに差し替えてください。

### 生地が多い場合（メタオブジェクト）
Shopify のセクションに置けるブロックは最大 50 個までで、初期データで 46 個使っています。生地を増やす場合は、管理画面の**メタオブジェクト**で生地を管理できます。

［設定］→［カスタムデータ］→［メタオブジェクト］→ 定義を追加：タイプ `suit_fabric`

| フィールドのキー | タイプ | 備考 |
| --- | --- | --- |
| `name` | 1行テキスト | 必須 |
| `color` | カラー | |
| `pattern` | 1行テキスト | `solid` `pinstripe` `chalkstripe` `check` `glen` `herringbone` `birdseye` |
| `pattern_color` | カラー | 任意 |
| `image` | ファイル（画像） | 任意 |
| `mill` / `origin` / `composition` | 1行テキスト | 任意 |
| `season` | 1行テキスト | `all` `ss` `aw`、または「オールシーズン」「春夏」「秋冬」 |
| `comment` | 複数行テキスト | テイラーのコメント |
| `pairing_products` | 商品（リスト） | 合わせたい小物 |

登録した生地は、ブロックの生地の後ろに自動で追加されます（セクション設定「メタオブジェクトの生地も読み込む」で切り替え）。生地の入れ替えはメタオブジェクトで行い、型やオプションをブロックに残す運用がおすすめです。

### 予約の受け取り方
仕上がり画面の来店予約フォームは、Shopify 標準のお問い合わせフォームとして送信され、［設定］→［通知］の送信先メールアドレスに届きます。選んだ仕様一覧・再現用 URL・来店希望日・ご要望が本文に入るので、来店前にお客様のイメージを把握できます。テーマ設定の「予約ページの URL」を入れると、外部の予約システムへのボタンも表示されます。

## 5. 確認していること・今後の検討事項

- `shopify theme check` 相当のチェック（`@shopify/theme-check-node`）でエラーなし。警告は Google Fonts の外部読み込みのみ（日本語フォントは Shopify のフォントライブラリにないため意図的）
- シミュレーターは Chrome でデスクトップ（1360px）とスマートフォン（390px）の表示・操作を確認済み
- 実ストアへの適用前に、テスト用ストア（開発ストア）でフォーム送信を確認してください

今後の候補：
- 生地写真の撮影（プレビューの質感が大きく上がります）
- 予約システムとの連携（日時枠の空き状況を表示する場合は、予約アプリの導入を検討）
- シミュレーション結果の画像保存、採寸データの事前入力
- 英語ページ（`locales/en.json` の追加）
